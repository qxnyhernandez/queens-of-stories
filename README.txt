QUEENS OF STORIES — VS CODE PROJECT

Files included:
- index.html: homepage and story library
- style.css: responsive brown-and-gold design
- script.js: search, genre filters, likes, details popups, theme toggle, and hero controls
- books.js: the 30 book records and original stories
- story.html and reader.js: individual story-reading pages
- images/: 30 individual illustrated cover artworks and story images

RUN IN VS CODE
1. Extract the ZIP file.
2. Open the extracted Queens_of_Stories_VSCode_Project folder in VS Code.
3. Open index.html and use the Live Server extension, or open the VS Code terminal in this folder and run: py -m http.server 8080
4. Visit http://localhost:8080

If using the Python server, use Ctrl+C in the terminal to stop it. The project does not require npm or any build step. Google Fonts are optional; the website uses fallback fonts if you are offline.
